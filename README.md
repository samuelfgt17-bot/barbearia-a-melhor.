# Barbearia A Melhor Tailândia — Site demonstrativo V2

Site não oficial, em Vite + React + TypeScript + Tailwind CSS.

## Abrir no Mac

1. Abra a pasta no VS Code.
2. No terminal: `npm install`
3. Depois: `npm run dev`
4. Abra `http://localhost:5173/`.

Para validar a publicação: `npm run build`.

## Dados e personalização

- `src/config.ts`: endereço, WhatsApp, Instagram, horários e lista sugerida de serviços.
- `src/App.tsx`: layout, textos e links.
- `src/style.css`: estilo responsivo preto e laranja.
